# cozy book shelf
📚 My Cozy Shelf – Your Personal Reading Corner

Welcome to My Cozy Shelf, a personalized favorite book collection web application designed to make your reading journey simple, organized, and enjoyable.

It provides a cozy digital space where readers can discover books, manage their personal collections, and keep track of their reading progress.

🌟 Features

- 🔐 User Authentication: Sign up and log in using Supabase authentication.
- 👤 My Profile: View your account details.
- 📖 Personal Book Collection: Add and manage your favorite books.
- 🔍 Book Discovery: Search and explore books.
- 📚 Reading Progress: Track your reading activity.
- 💾 Local Storage: Save your book collection in the browser.
- 📱 Responsive Design: Access the application on different screen sizes.
- 🚪 Logout: Securely sign out of your account.

🚀 Getting Started

1. Clone this repository:
   
   git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder in VS Code.

3. Configure your own Supabase project credentials in "supabase.js".

4. Open "index.html" using VS Code Live Server or a local web server.

5. Explore My Cozy Shelf!

🔒 Authentication Setup

This project uses Supabase for user authentication.

To run it with your own Supabase project:

- Create a Supabase account.
- Create a new project.
- Get your Project URL and Publishable Key.
- Add them to "supabase.js".
- Configure the authentication settings and redirect URLs.

Note: Never publish your Supabase Secret or Service Role Key in frontend code.
